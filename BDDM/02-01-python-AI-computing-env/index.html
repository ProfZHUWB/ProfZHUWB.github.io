开发和运行机器学习模型需要 Python、pandas、Scikit-learn 等诸多软件。如果自己有台性能不错的电脑，可以自己把需要的软件下载安装，搭建一个自己的开发平台。对于初学者来说，更容易的方案是通过浏览器直接使用在线平台来编辑和运行程序。比较有影响力的在线平台有三个：

  1. 阿里云天池实验室，由阿里云提供每次登录可以连续使用 8 个小时，可以使用 5GB 空间保存数据。天池平台每年举办多次数据分析比赛，积累了很多数据集和参赛选手分享的代码。为学习数据分析提供了比较多的真实场景。
  2. Google colab 由谷歌提供。可以直接在浏览器内编辑和运行 jupyter notebook 代码。美中不足，国内无法直接连接，需要翻墙。
  3. Kaggle 英文版数据分析比赛的网站。天池实验室实际上是在模仿这个网站。Kaggle 每年举办大量数据分析比赛。有很多数据集和相关分析代码。

编程语言 Python

在机器学习领域，Python 是比较多人使用的主流编程语言。很多常见的机器学习的算法与模型都有 Python 版本。除了 Python 其它主流编程语言也对机器学习有不同程度的支持，比如 R 语言、Matlab、Java、C++。

Python 相对比较容易上手，属于中等篇容易的编程语言，比较适合编程小白。语言本身比较简洁，特别适合开发中小规模的应用。通常完成一个编程任务需要的时间比 Java/C++ 等语言少很多。

Python 语言有两个大的版本 2.0 与 3.0 它们的语法有比较大的不同。

机器学习三大主流框架

基于 Python 有三大免费、开源的主流机器学习框架

  1. scikit-lern 包含很多经典的机器学习算法和模型，比如 决策树、随机森林、支持向量机、神经网络、GBDT。适合基于表格数据的预测与回归任务。比如每一行代表一条贷款记录，每一列记录贷款的信息比如贷款人、金额、是否有逾期还款。基于历史数据学习一个分类模型，预测一笔贷款预期不还的可能性。特别适合中小规模数据（比如几千至几十万条），探索和对比多种机器学习算法的优劣。比较难处理超大规模任务，比如几百万条、甚至几亿条记录。
  2. PyTorch，由 Facebook 主推。很多研究神经网络科的研人员和学者使用。如果电脑有安装英伟达显卡，可以利用显卡加速机器学习模型的训练。对于训练大的神经网络，比如人脸识别、车牌识别、机器翻译这种类型的模型，往往可以加速几倍甚至几十倍。语法比较简单。因为很多学者使用，并且大家会把模型的代码分享出来，所以比较适合尝试探索新模型。
  3. Tensorflow/Keras，由 Google 主推。适合训练超大规模模型，与 PyTorch 一样支持用英伟达显卡加速训练机器学习模型。适合大规模部署学习好的模型。比如做好了贷款违约预测模型，要把它上线，自动审批客户的贷款申请。这个时候用 Tensorflow 就比较方便，因为很多网站的后台服务是由 Java 语言开发的，前端手机 app 可能又要用到 Javascript，而 Tensorflow 支持多种语言开发。但是，对于做数据分析的人来说，直接使用 Tensorflow 比较复杂。新版的 Tensorflow 提供了 Keras，对开发和训练常用机器学习模型进行了些简化。比直接使用 Tensorflow 容易很多。

其它常用软件

  1. pandas 很多时候，我要处理的是表格数据。要对表格进行筛选、合并、查询、分组统计等工作。Pandas 实现了很多基本的表格操作、展示等功能。它比 excel 更强大。当然如果很熟悉 excel 的学员，也可以用 excel 处理数据，处理好的数据保存成 *.xlsx 或者 *.csv 文件。机器学习算法，需要从文件读入数据的时候，也可以用 pandas 很方便的读取我们保存的 *.xlsx 或者 *.csv 文件。
  2. matplotlib 主要用来绘图展示数据，比如箱线图、饼图、柱状图等。
  3. numpy 是 Python 中做科学计算常用的软件库。很多机器学习算法需要用到它。
  4. jupyter notebook 把程序、文字说明、计算结果、生成的图表在一个文件中统一展示的文件格式。适合交流和分享想法的文件格式。本课程提供的程序都以 notebook 的格式保存。

天池实验室实际上由两部分构成：一是天池 nootebook, 它更像一个论坛，允许用户管理、发布自己的程序；二是 Data Science Workspace (DSW), 它是一台安装了 Python 开发环境的虚拟机。当用户要编辑 天池 nootebook 中的一个 notebook 程序时，实际上会自动启动一台 DSW 虚拟机，然后把 notebook 下载到这台虚拟机的 Download 目录下，然后启动一个 案例开发的 IDE 来编辑这个 notebook。用户可以用 DSW 编辑、运行程序。得到想要的结果、或者程序修改完成后，可以把结果下载到自己的电脑，把程序保存到 天池 nootebook 中。

  1. 在 天池Notebook 页面左下角红色箭头处选中要删除的文件，选中的文件的背景会变成灰色。 点右上角蓝色箭头处的 编辑 按钮。
