Iterative Deepening A* Algorithms for the Container Relocation Problem

This page is maintained by Dr. Wenbin Zhu to suppliment the article "Iterative Deepening A* Algorithms for the Container Relocation Problem" accepted to IEEE Transactions on Automation Science and Engineering.

Introduction

The container relocation problem, where containers that are stored in bays are retrieved in a fixed sequence, is a crucial port operation. Existing approaches using branch and bound algorithms are only able to optimally solve small cases in a practical time frame. In this paper, we investigate iterative deepening A* algorithms (rather than branch and bound) using new lower bound measures and heuristics, and show that this approach is able to solve much larger instances of the problem in a time frame that is suitable for practical application. We also examine a more difficult variant of the problem that has been largely ignored in existing literature.

Data Sets

Download: detailed-solutions.7z

There are a total of three data sets.

  1. Caserta et. al. 2009 proposed a set of test instances for the restricted variant of container relocation problem (refereed as Block Relocation Problem). More information can be found on their website. We have converted their instances into our input format by setting T = h+2.
  2. Lee and Lee 2010 studied the extension of container relocation problem, where multiple bays are involved. Among the instances generated by Lee and Lee, 14 are single bay instances. More information can be found on their website. We have converted their instances into our input format.
  3. We generated a set of 12500 new instances. Each test case is composed of three parameters N, S and T. First, N containers are generated whose retrieval orders are a random permutation of 1, 2, ..., N. For each container, randomly select an incomplete stack s from 1, 2, ..., S and place it on top of the stack, until all containers are placed into the layout. A total of 125 sets of instances are generated, with S range from 6 to 10, T range from 3 to 7 and N range from (S-1) * T, to S * T - 1; 100 instances were generated for each combination of S, T and N.

Four Algorithms for Two Variants of CRP

  • Restricted Variant: only containers above the target can be relocated.
    1. IDA*-R: Iterative Depeening A* for Restricted Variant
  • Unrestricted Variant: any container on top of any stack can be relocated.
    1. IDA*-U: Iterative Depeening A* for Unrestricted Variant
    2. IDA*-UM: Same as IDA*-U, a map is used to avoid visiting duplicated nodes
    3. IDA*-UM3: Same as IDA*-UM, a more aggressive lower bound (not admissible) is used
