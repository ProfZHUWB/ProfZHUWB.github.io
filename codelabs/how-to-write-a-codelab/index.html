  2. 在浏览器输入地址 https://codelabs-preview.appspot.com/?file_id=[google-doc-id] 生成预览
  3. 发布 【TODO】

离线写作：

  1. 到 官方 适合你系统的版本，比如 claat-windows-amd64.exe ，保存为 claat.exe
  2. 按照 这个格式 用任意文本编辑器比如 notepad 写一个文件保存为 *.md ，用utf-8编码保存避免中文出现乱码。文件开头的 id: 后是保存生成的 html 文件的目录
  3. 运行 claat 命令生成 html 文件：claat export 文件名.md
  4. 双击 how-to-write-a-codelab/index.html 文件用浏览器打开检查效果
  5. 把生成的目录 how-to-write-a-codelab/ 整个上传 gitee.com 用 pages 服务发布即可给国内用户浏览。也可以上传 github.com 国内用户需要翻墙浏览

claat 需要调用 Google 的 codelabs-preview 服务，所以需要有一个 Goolge 账号，并已经用 Chrome 登录才能使用

生成的 index.html 文件会用到 http://*.googleapis.com 上的字体和css文件，浏览器需要下载对于的资源，国内刷新会比较慢，约1分钟。

claat 生成的是静态 html 文件，用到 http://*.googleapis.com 资源不需要翻墙就可以使用

下载本教程的源文件，压缩到一个目录比如 C:\codelab。可以看到以下文件

claat.exe

claat-windows-amd64.exe 2.2.0 版本

how-to-write-a-codelab-assets

本教程用到的图片等资源文件

how-to-write-a-codelab.md

本教程的 markdown 文件

打开 cmd 命令行窗口，并进 c:\codelab 目录，运行 claat.exe 生成 html 文件

c:\codelab> claat.exe export how-to-write-a-codelab.md
ok      how-to-write-a-codelab

成功生成 html 文件并保存在 how-to-write-a-codelab 目录下。

*.md 文件里面引用到所有本地图片等资源都会复制到生成的目录下。
